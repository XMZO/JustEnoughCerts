Just Enough Certs（JEC）是一个自托管的证书管理面板：获取证书、自动验证域名、部署到 CDN 和服务器、到期前自动续期。界面的任务只有一个：让人一眼看清哪些证书正常、哪些需要处理，并且能马上处理。整体冷静、克制、信息密度适中；唯一的个性元素是向 Minecraft 的 JEI 致敬的**耐久条**和**物品栏格子**。

## 文案与语气

- 简体中文和英文同等对待：每句话都先在 `zh-CN` 和 `en-US` 两个语言文件里各写一份，代码里不出现任何界面文字。
- 句子大小写，不用感叹号，不用 emoji，不卖萌。用用户能懂的词，不用实现细节的词：写“部署到阿里云 ESA”，不写“执行 Target”。
- 按钮动词开头，说清楚点击后发生什么：“签发证书”“测试连接”“部署”。同一个动作在按钮、确认框和结果提示里用同一个词（“部署” → “已部署”）。
- 错误信息说明发生了什么、怎么修复，不道歉：“DNS 记录还没有生效。已等待 5 分钟，请确认 `_acme-challenge` 记录已添加。”
- 空状态是行动入口：“还没有证书。添加第一张证书，JEC 会在到期前自动续期。”
- 固定术语（中 / 英）：证书 Certificate、签发 Issue、续期 Renew、重签 Reissue、域名验证 Domain validation、来源 Source、部署目标 Deploy target、凭据 Credential、通知 Notification、模块 Module。状态名见 StatusBadge。
- 时间和数字交给 `Intl` 按语言格式化，剩余天数写“剩 23 天 / 23 days left”，过期写“已过期 2 天 / Expired 2 days ago”。

## 颜色

- 三层底色：页面用 `surface`，面板、表格、输入框用 `surface-raised`，凹陷区域（证书格子、表头、代码块、悬停行）用 `surface-sunken`。层次靠 `line` 边框区分，不靠阴影。
- 文字只用 `ink`（正文、标题）和 `ink-muted`（说明、时间、表头）。
- `brand` 绿只用于：主按钮、链接、当前导航项、选中状态和焦点环（`focus-ring`）。不要把品牌绿当作“正常”状态的大面积填充。
- 状态颜色固定成套使用：标签底色用 `*-soft`，文字和图标用 `*-ink`，耐久条填充用 `*-fill`。
  - `ok-*`：正常；`warn-*`：进入续期窗口；`danger-*`：已过期或失败；`info-*`：签发中、部署中。
- 任何状态都必须同时有**图标和文字**，不能只靠颜色。唯一的例外是紧凑列表里的“正常”行：只用 `circle-check` 图标，完整状态写进这一行的 `aria-label`；其他状态照样写出状态词。
- 主按钮文字用 `on-brand`，危险按钮用 `danger-ink` 作底色、`on-danger` 作文字，深色主题下不要写死白色。

## 耐久条与物品栏格子

- **LifeBar（耐久条）**表示证书剩余寿命：方角细条，底槽永远是深色 `bar-track`（深色主题加 `bar-edge` 描边），按剩余天数换填充色：`ok-fill` → `warn-fill`（≤ 续期阈值，默认 30 天）→ `danger-fill`（≤ 7 天或已过期）。旁边必须写剩余天数。
- **CertSlot（物品栏格子）**是总览页的主视觉：每张证书一个 `slot-size` 方格，内凹斜面 `shadow-slot`，底部嵌一根缩小的耐久条，按剩余天数从少到多排列。
- 这两个造型只表示证书寿命，不用于上传进度、配额等其他场景，保持比喻纯粹。全站其他地方保持朴素。

## 文字

- 只用系统字体，不打包网页字体：`sans` 用于全部界面文字，`mono` 只用于指纹、序列号、DNS 记录、Key ID 和日志。域名本身用 `sans`。
- 样式：页面标题 `page-title`（每页一次），面板标题 `section-title`，卡片和表格主域名 `heading`，正文 `body`，次要信息 `small`，状态标签和角标 `caption`，总览数字 `numeral`。
- 剩余天数、日期、数量一律用等宽数字（`font-variant-numeric: tabular-nums`），对齐后方便扫读。
- 不用全大写标签，不在标题上方加小字眉标。

## 间距与布局

- 4px 网格：`space-1` 到 `space-8`。面板内边距 `space-4`，面板之间 `space-4`，手机端页面左右留白 `space-4`。
- **密度优先，不靠折叠和分页**：列表用紧凑行（桌面表格 `jec-table--compact` 行高约 44px；手机端证书列表默认把需要处理的证书排成整行、正常的证书排成两列小格，见 CertRow）；宽度放得下的面板就并排，不上下堆叠；长列表用筛选和搜索收窄，不用折叠栏、手风琴和分页把内容藏起来。
- 断点：小于 `bp-tablet`（640px）用底部标签栏，表格变成 CertItem 列表加两列小格；640px 到 `bp-desktop`（1024px）之间侧栏可折叠；1024px 以上侧栏常驻，宽 `sidebar-width`。
- 手机端可点击元素的最小高度为 `touch-target`（44px）。
- 内容左对齐；数字列右对齐；不居中排版正文。

## 形状与层次

- 圆角分三级，按层级用：`radius-sm`（证书格子、状态标签、小标签）、`radius-md`（按钮、输入框、菜单项）、`radius-lg`（面板、对话框、手机端卡片）。不要所有东西都用同一个圆角。
- 阴影只有两处：`shadow-popover`（下拉菜单、对话框、提示框）和 `shadow-slot`（证书格子）。面板和卡片没有阴影。
- 不用渐变、毛玻璃和彩色左边框卡片。

## 图标

- 使用 Lucide（线性图标，描边 2），与文字同行时 16px，导航里 20px，颜色继承文字颜色。
- 状态图标固定：正常 `circle-check`、即将到期 `triangle-alert`、已过期 `circle-x`、失败 `octagon-x`、进行中 `loader-circle`、未部署 `circle-dashed`。
- 不用 emoji 当图标。只有图标的按钮必须有 `aria-label`。

## 动效

- 唯一的常驻动效是进行中状态的 `loader-circle` 旋转。
- 用户操作的反馈（展开、切换、保存成功）可以用 150ms 以内的过渡，说明“什么变了”。不做入场动画。
- 用户开启“减少动态效果”时停止所有动画。

## 国际化

- 所有文字来自 `i18n/locales/` 下的语言文件，组件只接收翻译 key 和参数。
- 按英文比中文长 30%–40% 预留空间：标签、按钮、表头都不写死宽度，长文本截断时提供完整内容的提示。
- 设计稿和测试都同时检查中文、英文和伪语言（加长 40%）三种情况。

## 无障碍

- 正文与底色对比度不低于 4.5:1，图标、控件边框、耐久条与底槽不低于 3:1，两种主题都已校验。
- 键盘焦点用 `focus-ring`：2px 实线，外偏移 2px，所有可交互元素都必须可见。
- 证书格子的 `aria-label` 写全：域名、状态、剩余天数。

## 标志

- `assets/Logos/jec-mark.svg` 是像素锁图标（提案版），单色 `#3c9a3f`，按 16px 的整数倍显示。标志旁的名称写 “Just Enough Certs” 或 “JEC”，用 `ink`、`sans` 600。
