# Button

按钮用于触发一个动作，文字写清楚点击后会发生什么。

- **调用方提供**：按钮文字（翻译 key）、可选的前置图标、`type`、点击处理、`disabled`。
- **变体**：`jec-btn--primary`（每个区域只放一个，用于本页最主要的动作，例如“签发证书”“保存”）、默认次按钮（“测试连接”）、`jec-btn--ghost`（“取消”、工具栏图标按钮）、`jec-btn--danger`（不可逆操作，例如“吊销证书”“删除凭据”，点击后必须二次确认）。
- **尺寸**：默认 36px 高，`jec-btn--sm` 30px 用于表格行内；手机端最小高度为 `touch-target`（44px）。
- **文字**：动词开头、句子大小写，不加箭头和感叹号；同一个动作在按钮、确认框、结果提示里用同一个词（按钮“部署”，提示“已部署”）。
- **只有图标的按钮**必须有 `aria-label`（同样来自翻译文件）。
- 不要写死宽度，英文通常比中文长 30%–40%。
