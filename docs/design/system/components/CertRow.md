# CertRow

证书列表的一行：桌面端是紧凑表格行（`jec-table jec-table--compact`，行高约 44px），窄于 `bp-tablet`（640px）时换成 CertItem 紧凑列表行。

- **调用方提供**：主域名、额外域名数量、状态、剩余天数与比例、来源名称、部署目标列表、行操作菜单。
- **列顺序**：域名 → 状态 → 剩余（横排耐久条 `jec-life--inline`）→ 来源 → 部署到 → 下次续期（内容区宽于 1000px 时显示）→ 操作。紧凑行内文字不换行，部署目标标签排成一行。域名用 `heading` 样式，额外的 SAN 只显示 `+N`，完整列表放到详情页。
- **卡片**（`jec-card`）只用于单张证书的摘要，例如总览里选中格子后的摘要；列表一律用表格行或 CertItem。
- **部署目标**用 `jec-tag`，写平台名加实例名（“Nginx：vps-01”），超过 3 个时显示前 2 个加“+N”。
- **签发中**的证书还没有有效期，剩余列显示“—”，不要画空的耐久条。
- **CertItem**（`jec-list` > `jec-item`）：左边状态图标，中间域名，右边剩余天数和迷你耐久条，整行可点击进入详情。
  - **需要处理**的证书（失败、即将到期、签发中）两行：第二行是状态词 + 一句原因或下一步（“DNS 记录没有生效，稍后重试”“今晚 02:00 自动续期”）。
  - **正常**的证书一行（`jec-item--single`），状态写进 `aria-label`。
  - 签发中的证书还没有有效期，右边留空。部署目标和来源只在详情页和桌面表格里显示。
- **手机端证书列表默认用两列格子**：需要处理的证书用 CertItem 列表，正常的证书用 `jec-tiles` 两列小格（`jec-tile`：域名 + 耐久条 + 天数）。两组各有一个小标题（`jec-group__title`，写组名和数量），标题不可折叠；按状态筛选后只剩一组时，另一组连标题一起不显示。
- 单列样式留作以后的“列表密度”设置：标准行（`jec-list`，需要处理 64px、正常 52px）和紧凑行（`jec-list--compact`，56px / 44px）。
