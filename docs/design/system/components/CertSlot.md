# CertSlot

物品栏格子：总览页把每张证书画成一个方格，底部是缩小的耐久条，一眼看出整体健康状况。

- **调用方提供**：域名（取主域名最左一段的前两个字母作为格子里的字，通配符证书显示 `*.`）、剩余比例和状态、可选的角标状态（失败 / 进行中）、完整的 `aria-label`（域名 + 状态 + 剩余天数，来自翻译文件）、点击处理。
- **交互**：点击或回车选中格子（`aria-pressed="true"`，品牌色描边），在格子下方或侧边显示该证书的摘要面板；双击或面板里的按钮进入详情。
- **角标**只在需要注意时出现：失败用 `danger-ink` 的 `octagon-x`，进行中用 `info-ink` 的旋转 `loader-circle`。正常证书没有角标。
- **空格子**（虚线框 + `plus`）放在最后，用于“添加证书”。
- **排序**：默认按剩余天数从少到多，最需要处理的排在最前面。
- 格子大小是 `slot-size`（56px）；手机端用 `jec-slot--sm`（48px），390px 宽的屏幕一行放 6 个。间距 `space-2`。格子用 `shadow-slot` 的内凹斜面，这是全站唯一用斜面的地方。
