# ChoiceCard

单选卡片：从 2 到 8 种方式里选一种，每种附一句说明，例如证书来源、域名验证方式。同一组里的说明写同一类信息（价格、有效期、限制），方便横向比较。

- **调用方提供**：选项列表（标题、说明，都是翻译 key）、当前值。
- 用 `role="radiogroup"` 包住，每张卡片是 `role="radio"` 的按钮；方向键在卡片之间移动。
- 卡片在 `jec-choices` 里自动换行，每张最窄 196px，手机端一行两张。
- 选中后，下面紧接着显示这一项需要的字段（直接显示，不放进折叠栏）。
- 多选用同一节里的 **Check 行**（`jec-check`）：原生复选框 + 名称 + 一行说明，适合“部署到哪些目标”这类列表。
