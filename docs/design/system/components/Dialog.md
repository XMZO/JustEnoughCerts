# Dialog

对话框：在当前页面上添加或编辑一项配置（部署目标、DNS 服务商、凭据），不离开页面。

- **调用方提供**：标题、内容、底部按钮。
- 结构：标题栏（标题 + 关闭按钮）→ 内容（可以滚动）→ 底部按钮。主按钮在最右，“测试连接”这类辅助操作靠左。
- 遮罩用 `ink` 的 45% 透明色；对话框用 `shadow-popover`，这是全站除了格子以外唯一的阴影。
- 打开时焦点移到第一个输入框，`Esc` 关闭，焦点回到触发按钮。
- 手机端对话框占满屏幕，底部按钮固定在屏幕底部。
- 删除这类不可撤销的操作用小对话框确认，按钮写清后果：“删除凭据”，不写“确定”。
