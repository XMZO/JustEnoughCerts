# Field

表单字段：标签 + 输入框 + 帮助文字（或错误提示）。服务商的配置表单由后端 Schema 自动生成，全部用这个组件。

- **调用方提供**：标签、帮助文字、占位文字、错误信息（都是翻译 key），以及值、类型、是否必填。
- **标签**写字段名本身，不加冒号；必填项不加星号，改为在可选项的标签后写“（可选）”。
- **帮助文字**告诉用户去哪里找这个值，或者它会被拿来做什么。
- **错误提示**说明哪里不对、怎么改，不道歉，不只说“格式错误”。
- **密钥类字段**保存后不再回显：占位文字写“已保存，留空表示不修改”。
- 域名、记录值这类技术内容的输入框可以加 `jec-code` 使用等宽字体。
- 手机端输入框最小高度为 `touch-target`（44px）。
