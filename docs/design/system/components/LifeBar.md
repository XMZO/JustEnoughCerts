# LifeBar

耐久条：用一根像 Minecraft 物品耐久度那样的细条，显示证书还剩多少有效期，旁边写明剩余天数。

- **调用方提供**：签发时间、到期时间、续期阈值天数（来自证书的续期策略）、剩余天数文字（翻译 key + 数字参数）。
- **长度**：`剩余时长 ÷ 本张证书的总有效期`，所以 200 天证书和 90 天证书都能直接比较“还剩几成”。
- **颜色**（只看剩余天数，不看比例）：
  - 剩余天数大于续期阈值（默认 30 天）→ 默认样式，填充 `ok-fill`；
  - 小于等于阈值 → `jec-life--warn`，填充 `warn-fill`，文字用 `warn-ink` 加粗；
  - 小于等于 7 天或已过期 → `jec-life--danger`，填充 `danger-fill`，文字用 `danger-ink` 加粗。
- **底槽**在两种主题里都是深色 `bar-track`，方角，不做圆角和渐变；深色主题加 `bar-edge` 描边。
- 天数文字必须显示，条本身只是辅助，不能单独靠颜色或长度传达信息。
- 文字在上、条在下（DOM 里条在前，读屏先读到条再读文字也可以），条的长度只取决于容器宽度，所以同一列里的耐久条可以直接比较，不会因为中英文文字长短不同而错位。
- **横排变体** `jec-life--inline`：条固定 88px 宽、天数写在右边，用于紧凑表格，一行就能放下，同一列的条依然等长可比。
- 这个造型只用来表示证书寿命，不要拿去做上传进度、配额之类的东西，保持比喻的纯粹。
