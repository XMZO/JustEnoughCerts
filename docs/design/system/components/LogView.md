# LogView

签发和部署日志：每行一个时间加一句话，正在运行时末尾有闪烁光标。

- **调用方提供**：日志行（时间、级别、消息 key 和参数）、是否仍在运行。
- 用 `role="log"` 和 `aria-live="polite"`，新行追加在末尾，自动滚到底；用户往上翻时停止自动滚动。
- 级别只有四种：普通（`ink`）、成功（`ok-ink`）、警告（`warn-ink`）、错误（`danger-ink`）。
- 消息写人话：“DNSPod：添加 CNAME …”，不直接贴原始 JSON；原始响应放在“完整日志”下载里。
- 密钥、Token 在日志里一律打码，只保留后 4 位。
