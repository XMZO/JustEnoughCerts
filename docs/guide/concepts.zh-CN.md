# 核心概念

[English](concepts.md)

本页说明 JEC 中的主要对象及其关系。界面中的各个页面均围绕这些对象组织。

## 证书与版本

- **证书**：一组域名（第一个为主域名），以及获取方式、部署目标与续期设置。证书是长期存在的逻辑对象。
- **版本**：证书的一次具体签发或上传结果，包含证书链、私钥与有效期。每次续期产生一个新版本，私钥随之更换；证书详情页的“历史版本”列出全部版本。

## 服务商

服务商是对外部服务的一份配置，分为以下四类，各有独立的页面：

| 类别 | 作用 | 示例 |
|---|---|---|
| 证书来源 | 签发或取回证书 | ACME 账号、Namecheap SSL Manager、阿里云签发的证书 |
| 验证方式 | 证明域名控制权 | DNS 服务商、网站目录、JEC 自己应答 |
| 部署目标 | 安装证书 | 阿里云 ESA 站点、Nginx Proxy Manager、本地目录 |
| 通知渠道 | 发送消息 | Telegram、邮件、钉钉、Webhook |

每类服务商有多种**类型**，由各个模块或插件提供；同一类型可添加多个**实例**，例如两个不同账号的 ACME 账号。手动上传的证书没有证书来源，也不需要验证方式。

## 凭据

凭据是一组可共用的密钥，例如阿里云 AccessKey 或 SSH 私钥。多个服务商可引用同一凭据，更换密钥时只需修改一处。“凭据”页列出每个凭据的使用者与最近使用时间。

## 签发、续期与部署

- **签发**：由证书来源为证书生成新版本。签发由添加证书、手动“立即签发”或续期触发，每一步及其日志记录在签发进度页。
- **续期**：证书进入续期窗口后自动发起的签发，详见[续期](../usage/renewal.zh-CN.md)。
- **部署**：将新版本安装到证书的每个部署目标。每个新版本（无论签发还是上传）都会自动部署；也可在证书详情页手动重新部署。

签发与部署失败时按指数退避自动重试，并可发出通知。全部签发、续期与部署记录汇总在“签发记录”页。

## 证书状态

| 状态 | 含义 |
|---|---|
| 正常 | 当前版本有效，未进入续期窗口 |
| 即将到期 | 已进入续期窗口 |
| 已过期 | 当前版本已过期 |
| 签发中 | 有签发正在进行或等待来源 |
| 签发失败 | 最近一次签发失败，且之后没有新版本 |
| 部署中 | 有部署正在进行 |
| 部署失败 | 到某个部署目标的最近一次部署失败 |

## 模块与插件

内核之外的功能均以模块实现，包括各类服务商与审计日志、线上巡检、单点登录等功能。模块可在“模块”页启用或停用，也可在编译时排除；实验性模块默认关闭。插件是外部程序，可在不重新编译的情况下新增服务商类型，参见[插件](../development/plugins.zh-CN.md)。
