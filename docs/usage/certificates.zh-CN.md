# 证书

[English](certificates.md)

“证书”页列出全部证书及其状态、剩余有效期、来源、部署目标与下次续期时间；在手机上，需要处理的证书单独列出并注明原因。各状态的含义见[核心概念](../guide/concepts.zh-CN.md#证书状态)。

## 添加证书

在“证书”页选择“添加证书”。添加方式取决于证书来源：

| 方式 | 说明 |
|---|---|
| 由证书来源签发 | 选择证书来源，填写域名，选择验证方式与密钥类型。提交后立即开始签发，此后自动续期 |
| 手动上传 | 来源选择“手动上传”，粘贴 PEM 文本（证书、中间证书与私钥，顺序不限），或上传 PFX/P12 文件及其密码。此类证书不会自动续期，到期前发出提醒 |
| 导入已有证书 | 选择“导入已有证书”，与手动上传相同，适用于迁移已有的证书 |

域名的处理规则：

- 第一个域名为主域名；通配符写作 `*.example.com`。
- 域名统一转换为小写，国际化域名转换为 Punycode，重复的域名自动去除。
- 通配符证书须使用 DNS 验证。
- 同一张证书（按指纹）只能添加一次。

密钥类型可选 RSA 2048/3072/4096 与 ECDSA P-256/P-384，默认值在设置页的“续期默认值”中设置。每次续期都会生成新的私钥。

## 证书详情

证书详情页包含：

- 剩余有效期、签发与到期时间、有效期长度与下次续期时间；
- 部署目标及每个目标最近一次部署的结果；
- 上次续期（或最近一次签发）的步骤与用时；
- 线上检查的结果，参见[续期](renewal.zh-CN.md#线上巡检)；
- 历史版本与证书链；
- 证书信息（域名、颁发者、来源、密钥、序列号与 SHA-256 指纹）与续期设置。

## 操作

| 操作 | 说明 |
|---|---|
| 立即签发 / 立即续期 | 立即开始一次签发，不等待续期时间 |
| 上传新证书 | 为证书添加新版本。新证书须包含原主域名，且到期时间晚于当前版本 |
| 选择部署目标 | 增删部署目标。新增的目标立即部署当前版本 |
| 立即部署 / 重新部署 | 将当前版本重新部署到全部或单个目标 |
| 下载 | 下载 ZIP 文件，内含 `cert.pem`、`chain.pem`、`fullchain.pem` 与 `privkey.pem`。文件含私钥，下载前须输入登录密码 |
| 删除证书 | 删除证书的全部版本与私钥。已部署到其他位置的证书不受影响 |

证书列表的每一行也提供上述常用操作的菜单。
