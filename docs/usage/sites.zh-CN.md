# 站点监控

[English](sites.md)

“站点监控”页跟踪不由 JEC 管理的网站证书，例如合作方或其他团队的网站：何时到期、浏览器是否信任。JEC 只连接这些网站，不做任何改动。

## 添加站点

1. 在“站点监控”页选择“添加站点”。
2. 填写主机名（端口不是 443 时带上端口）或网址，如 `https://example.com`；名称可选。
3. JEC 立即检查一次，此后每 6 小时检查一次，连不上时 1 小时后再试。每行的“立即检查”可随时重新检查。

| 状态 | 含义 |
|---|---|
| 正常 | 证书可信，剩余三周以上 |
| 即将到期 | 剩余三周或更短 |
| 已过期 | 已超过到期时间 |
| 证书不可信 | 并非由受信任的 CA 签发，或不适用于该主机；原因显示在下方 |
| 连不上 | 该端口没有 TLS 响应；保留上次看到的证书信息 |

## 提醒

开启“监控的站点证书快到期或已经过期时通知”事件（默认开启）的通知渠道，会在到期前三周、一周以及到期后各收到一次提醒；站点更换证书后重新计算。监控的站点也包含在 [Prometheus 指标](../operations/monitoring.zh-CN.md)中。该页面由“站点监控”模块提供，可在“模块”页停用。
