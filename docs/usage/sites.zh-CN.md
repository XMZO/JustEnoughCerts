# 到期监控

[English](sites.md)

“到期监控”页跟踪 JEC 不负责续期、但到期会导致网站出问题的事物，以及并非由 JEC 申请的域名证书：

- **站点证书**：不由 JEC 管理的网站证书，例如合作方或其他团队的网站：何时到期、浏览器是否信任。JEC 只连接这些网站，不做任何改动。
- **域名注册**：证书与监控的站点所在域名的注册到期时间，经 RDAP（没有时用 WHOIS）向注册局查询。
- **证书透明度**：CA 为证书所在域名签发的全部证书（来自公开日志），用于发现为他人签发的证书。默认关闭。

## 添加站点

1. 在“到期监控”页选择“添加站点”。
2. 填写主机名（端口不是 443 时带上端口）或网址，如 `https://example.com`；名称可选。一次添加多个站点时每行一个，无法添加的连同原因保留在框中。
3. JEC 立即检查一次，此后每 6 小时检查一次，连不上时 1 小时后再试。每行的“立即检查”可随时重新检查。

| 状态 | 含义 |
|---|---|
| 正常 | 证书可信，剩余三周以上 |
| 即将到期 | 剩余三周或更短 |
| 已过期 | 已超过到期时间 |
| 证书不可信 | 并非由受信任的 CA 签发，或不适用于该主机；原因显示在下方 |
| 连不上 | 该端口没有 TLS 响应；保留上次看到的证书信息 |

站点只发送了证书本身、没有发送中间证书时，若按证书中的颁发者地址（AIA）补齐后可以验证，状态按到期时间显示，并另外标出“缺少中间证书”：电脑上的浏览器会自行补齐，但许多 App、安卓设备和 curl 会验证失败。

## 域名注册

证书与监控的站点所在的注册域名（如 `www.shop.co.uk` 对应 `shop.co.uk`）自动加入列表，证书删除后随之移除；IP 地址、内网名称与 `example.com` 等示例域名不计入。其他域名可通过“添加域名”手动加入。

1. JEC 按 IANA 发布的 RDAP 服务器列表向注册局查询到期时间与注册商；该后缀没有 RDAP 时（如 `.cn`、`.io`、`.co.uk`），改用 IANA 列出的 WHOIS 服务器。每天一次；即将到期时每 12 小时一次，以便尽快看到续费结果。
2. 证书详情页的“域名注册”一行显示该证书所在域名的到期日。

| 状态 | 含义 |
|---|---|
| 正常 | 剩余 30 天以上 |
| 即将到期 | 剩余 30 天或更短 |
| 已到期 | 已超过注册局给出的到期时间 |
| 查不到到期时间 | 该后缀的注册局既没有 RDAP 也没有 WHOIS 服务，或不公开到期时间（如 `.de`）；7 天后再查 |
| 查询失败 | 注册局没有响应或返回错误；保留上次的结果，2 小时后再试 |

查询只发往 IANA 与各注册局的公网 RDAP、WHOIS 服务器，内容仅为域名本身。

## 证书透明度

CA 签发的每张证书都会记录在公开的证书透明度日志中。JEC 经 [Cert Spotter](https://sslmate.com/certspotter/) 查找其证书所在的注册域名及其下各级名称的证书，并找出不是 JEC 管理的证书：公钥与 JEC 的任何证书都不同的证书。

1. 在“到期监控”页的“证书透明度”中选择“开启”。开启即把这些域名发送给 SSLMate 的 Cert Spotter。
2. 可选：在“API 密钥”中填写 Cert Spotter 的 API 密钥。没有密钥时 Cert Spotter 每小时只响应少量查询，其余域名由 JEC 稍后再查。

JEC 每 6 小时查找一次每个域名。第一次查找发现的证书在开启前就已存在，列为“开启前已有”，不提醒。之后发现的证书在 2 小时后（留给 JEC 保存自己签发的证书）仍认不出时提醒，并列为“需要查看”。每张证书可以：

| 操作 | 效果 |
|---|---|
| 信任同类 | 同一颁发者为相同域名签发的证书不再提醒，适用于 Cloudflare 等 CDN 自行签发的证书；列在“已信任”中，可“取消信任” |
| 忽略 | 只将这一张移出列表 |
| 监控站点 | 将其中一个域名加入站点监控 |
| 交给 JEC | 以这些域名添加一张由 JEC 签发和续期的证书 |
| 查看 | 在 crt.sh 上打开该证书 |

无人申请的证书可能意味着他人控制了域名的 DNS 或网站：请查明原因，并联系 CA 吊销该证书。证书透明度已对真实的 Cert Spotter 实测过（未使用 API 密钥）。

## 提醒

| 事件（通知渠道设置中） | 默认 | 提醒时间 |
|---|---|---|
| 监控的站点证书快到期或已经过期时通知 | 开启 | 到期前三周、一周以及到期后各一次；站点更换证书后重新计算 |
| 域名注册快到期或已经过期时通知 | 开启 | 到期前 30 天、7 天以及到期后各一次；续费后重新计算 |
| 证书透明度日志里出现不是 JEC 管理的证书时通知 | 开启 | 每张证书一次，发现 2 小时后 |

需要留意的站点、域名与证书显示在总览中，并计入浏览器标签页标题的数字。站点与域名的到期时间也包含在 [Prometheus 指标](../operations/monitoring.zh-CN.md)、日历订阅与 Telegram 机器人的 `/sites` 中。该页面由“到期监控”模块提供，可在“模块”页停用。
