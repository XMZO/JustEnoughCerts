# 证书透明度

[English](transparency.md)

CA 签发的每张证书都会记录在公开的证书透明度日志中。JEC 经 [Cert Spotter](https://sslmate.com/certspotter/) 查找其证书所在的注册域名及其下各级名称的证书，并找出不是 JEC 管理的证书：公钥与 JEC 的任何证书都不同的证书。默认关闭。

## 开启

1. 在侧栏打开“证书透明度”（手机上在“更多”中），选择“开启”。开启即把这些域名发送给 SSLMate 的 Cert Spotter。
2. 可选：在“API 密钥”中填写 Cert Spotter 的 API 密钥。没有密钥时 Cert Spotter 每小时只响应少量查询，其余域名由 JEC 稍后再查。

JEC 每 6 小时查找一次每个域名；“立即查找”可随时查找。

## 发现的证书

第一次开启前签发的证书（按证书的生效时间）列为“开启前已有”，不提醒。开启后签发的证书，包括之后才有 JEC 证书的域名下的，在 2 小时后（留给 JEC 保存自己签发的证书）仍认不出时提醒，并列为“需要查看”。

同一颁发者为相同域名签发的证书（如 CDN 或其他工具反复续期的证书）合为一行，显示张数与最近一张的有效期。列表分页显示，每页的行数按窗口高度确定。每一行可以：

| 操作 | 效果 |
|---|---|
| 信任同类 | 同一颁发者为相同域名签发的证书不再提醒，适用于 Cloudflare 等 CDN 自行签发的证书；列在“已信任”中，可“取消信任” |
| 忽略 | 将这一行的证书移出列表 |
| 监控站点（菜单） | 将其中一个域名加入[站点监控](sites.zh-CN.md) |
| 交给 JEC（菜单） | 以这些域名添加一张由 JEC 签发和续期的证书 |
| 查看（菜单） | 在 crt.sh 上打开这一行最近的一张证书 |

无人申请的证书可能意味着他人控制了域名的 DNS 或网站：请查明原因，并联系 CA 吊销该证书。证书透明度已对真实的 Cert Spotter 实测过（未使用 API 密钥）。

## 提醒

| 事件（通知渠道设置中） | 默认 | 提醒时间 |
|---|---|---|
| 证书透明度日志里出现不是 JEC 管理的证书时通知 | 开启 | 每张证书一次，发现 2 小时后 |

需要查看的证书显示在总览中，并计入浏览器标签页标题的数字，也包含在每周概况、[Prometheus 指标](../operations/monitoring.zh-CN.md)与 Telegram 机器人的 `/sites` 中。该页面与[到期监控](sites.zh-CN.md)页同由“到期监控”模块提供，可在“模块”页停用。
